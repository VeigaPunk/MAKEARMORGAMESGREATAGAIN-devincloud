# The World's Hardest Game — ship record

Original: The World's Hardest Game (Snubby Land, 2007) — precision
dodge-and-collect mazes; red square, blue patrol dots, yellow coins arm the
goal, checkpoints, instant respawn, death counter. Shipped title (original
evocation): **THE WORLD'S CRUELEST GAME**.

## Survey (2026-09-22)

| Rendition | Location | State |
|-----------|----------|-------|
| Standalone tree | `hardest/` | 114 levels (8 tiers), engine+autopilot validator, menu/save/medals/touch verified; HIGH menu crashes D-45/D-47 open at checkpoint |

No monorepo app, no prototype for this title.

## Decision: ADOPT in place (binding)

Zero-dependency, validated, closest to ship. No re-architecture. The shipped
copy `games/hardest/` is generated by `node tools/ship-build.mjs --only
hardest` (copies the tree verbatim, retitles the page).

## Phase 1 lane report (2026-09-23)

**Defects (verification/divergence.md) — all fixed and live-verified:**
- **D-45** (HIGH): `loadSave()` rewritten with full schema validation —
  corrupt `best` entries (wrong shape, NaN, negative, bad medal) are dropped,
  valid ones kept, menu survives. Live: seeded `hardest.save.v1` with a valid
  entry + 3 corrupt variants → reload → menu alive, valid entry kept.
- **D-47** (HIGH): `MEDAL_COL` defined (gold/silver/bronze); medaled tiles
  render medal pips + best stats without crashing. Live: silver-medaled save
  renders the 114-tile menu (previously the crash point).
- **D-65**: `blur`/`visibilitychange` clear the held-keys set + joystick.
- **D-50**: L30 patrol no longer crosses wall row 12 (corpus wall-crossing
  scan: only inherent diagonal corner-clips remain — by-design dot behavior).
- **D-66**: locked-tile click → red rejection flash (0.6s decay) + error
  blip. Live: 348 red pixels sampled at the tile 100ms after real pointer
  click.
- **D-48**: manifest/pars regenerated at 114/114; DIFFICULTY.md regenerated.

**Levels 109/111 (autopilot fails) — root-caused and redesigned:**
- 109-vault-door: a parked (zero-length-path) mover permanently sealed the
  door tile → bot dithered forever. Movers now sweep with timing windows.
- 111-portal-press: 4 pads — the goal-side pad teleported the bot back on its
  beeline → infinite shuttle. Goal corner sealed so the shortcut pad is the
  only way in (one-way shortcut, theme kept).
- Validator: **114/114 levels PASS, exit 0** (before: 112/114, exit 1).

**Polish (hardest-handoff P0–P2):**
- Death: red screen flash + 22-particle burst + two-tone crunch + 0.15s
  respawn. Coin: pitch-climbing ding (streak-based) + sparkle. Goal: green
  flash + 4-note sting + confetti burst + medal reveal.
- Player trail (26 samples, 0.22s fade); patrol dots radial-gradient shine;
  coins pulse; movers carry direction arrows; keys/doors/telepads/checkpoints
  have distinct glyphs (key, barred door, swirl, flag); background grid +
  vignette.
- Menu: hover/tap highlight, footer with level name/tier/best, `N` = next
  unplayed, locked tiles drawn with padlock + rejection feedback.
- Pause overlay (Esc) with Resume/Restart/Menu (Q) + tap targets; per-level
  best (deaths+time+medal) in HUD and saved; 1.1s level intro card
  (skippable, also skipped by probe input for automation).
- Music: menu + play beds (WebAudio 2-track loop, ~96 BPM), M mute, music
  mode switch verified via `__maga.music`.

**Debug hooks:** `?debug` → `__hardest` (always) + `__maga` (state/save/
music/start/input). Probe `input(x,y)` drives the same joystick vector path
as real touch.
